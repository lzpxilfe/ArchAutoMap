# ArchAutoMap

> QGIS 3.x용 문화유적 도면 자동화 플러그인

**Author:** `lzpxilfe (balguljang2)`  
**License:** `GPL-2.0-only`

`ArchAutoMap`은 수백 개의 유적이 들어 있는 폴리곤 레이어에서 **현재 보고 싶은 유적 1건만 깔끔하게 분리해** 수치지형도 위에 배치하고, 자동 축척과 중심 정렬을 적용해 **JPG 도면으로 빠르게 출력**할 수 있게 돕는 플러그인입니다. 

특히 최신 버전에서는 **이전 시기(Before) 레이어 결합** 기능이 추가되어, 유적명 오타가 있더라도 면적/중첩도 기반의 고도화된 공간 매칭을 수행해 **Before/After 짝꿍 도면**을 한 번에 뽑아낼 수 있습니다.

## ✨ 핵심 기능

- 🗺️ **배경 레이어 1개 + 유적 채움 레이어 1개 + 외곽선 레이어(선택)** 지원
- 🔎 **유적명 검색 후 단건 미리보기** 지원
- 🧭 **자동 중심 정렬 + 자동 축척 계산** 지원
- 📐 **면적 규칙표 + 점유율 보정**으로 너무 작거나 큰 도면 비율을 자동 조정
- 🎯 **도면 점유율을 숫자와 원형 도식**으로 직관적으로 표시
- 🧱 **원본 레이어를 건드리지 않고 임시 메모리 레이어로 렌더링**
- 🎨 **기본은 원래 레이어 심볼 유지**, 필요할 때만 표현 설정 덮어쓰기
- 🏷️ **표현 설정을 켠 경우 속성값별 채움색 규칙**을 `+` 버튼으로 추가 가능
- 🖼️ **현재 유적 1건 출력**과 **전체 유적 일괄 출력** 모두 지원
- 🧾 **기존 Layout 재사용** 또는 **자동 Layout 생성** 둘 다 지원
- ⏳ **이전 시기(Before) 레이어 다중 결합 (최대 5개)** 및 스타일 오버레이 설정 지원
- 🤝 **고도화된 양방향 공간 매칭 Fallback**: 유적명 오타나 유실 시 Before-After 유적의 공간 중첩률(70% 이상) 및 면적 범위(10%~300%) 검증을 통해 본체 유적을 정확히 추적
- 🛡️ **MultiPolygon 뷰포트 안정화**: 멀리 떨어진 노이즈 노드로 인해 축척이 흐트러지는 것을 방지하기 위해 면적이 가장 큰 본체(Main Part) 기준으로 뷰포트 산정
- 📏 **사방 여백 맥락 버퍼 개편**: 유적 크기와 관계없이 지정한 지상 거리(m)만큼 사방 여백이 확실히 확보되도록 축척 자동 계산식 개선

## 🧠 이런 작업에 잘 맞습니다

- 분포도 레이어에서 **유적 하나씩 보고서용 도면**을 뽑아야 할 때
- 같은 형식의 도면을 **반복적으로 수십~수백 장 출력**해야 할 때
- 기존 QGIS Layout을 유지하면서 **지도 extent만 자동으로 맞추고 싶을 때**
- 도면에서 유적이 **너무 작거나 너무 크게 들어가는 문제를 줄이고 싶을 때**
- Before(이전시기) 도면과 After(이후시기) 도면의 **경계선 위치를 일치시킨 짝꿍 도면**을 출력해야 할 때

## ⚙️ 작동 방식

ArchAutoMap은 원본 레이어에 필터를 직접 걸지 않습니다.  
선택한 유적 1건만 임시 메모리 레이어로 복사한 뒤:

1. 출력 CRS로 geometry를 맞추고
2. MultiPolygon인 경우 가장 면적이 넓은 본체(Main Part) 기하로 대표 뷰포트 범위와 축척을 결정한 뒤
3. 도면 안에서 유적이 차지하는 비율 및 사방 여백 최소 거리(`min_context_buffer_m`)를 함께 보정하고
4. Before 도면 출력 시, 설정된 Before 레이어에서 이름 혹은 공간 매칭(중첩률 70%, 면적비 10%~300% 하한/상한 필터링 및 150m 인접 안전 조건)으로 대상 피처를 발굴하여 오버레이한 뒤
5. 중심 정렬된 extent를 바탕으로 최종 JPG로 내보냅니다.

이 방식 덕분에 원본 프로젝트 상태를 전혀 건드리지 않으면서 깔끔하고 무결한 출력이 가능합니다.

## 🧩 입력 조건

- **배경 레이어**: 필수 (지형도 등)
- **유적 채움 레이어**: 필수 (After 유적 등)
- **유적 외곽선 레이어**: 선택
- **이전 시기(Before) 레이어**: 선택 (최대 5개 결합 가능)
- **유적명 필드**: 필수 (Before 레이어와 After 레이어 공통 매칭 기준)
- **면적 필드**: 선택 (비어 있으면 geometry 면적으로 직접 계산)
- **출력 CRS**: 기본값 `EPSG:5186` (미터 기반 투영좌표계만 지원)

## 🚀 설치 방법

1. 이 폴더 전체를 QGIS 사용자 플러그인 폴더에 복사합니다.
2. Windows 기본 경로는 아래와 같습니다.
   - `C:\Users\<사용자명>\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins\ArchAutoMap`
3. QGIS를 다시 시작합니다.
4. `플러그인 관리 및 설치`에서 `ArchAutoMap`을 활성화합니다.
5. 활성화 후 상단에 `ArchAutoMap` 전용 툴바가 보이지 않으면 QGIS를 한 번 더 재시작합니다.

## 🛠️ 사용 순서

1. 배경 레이어, 유적 채움 레이어, 외곽선 레이어를 선택합니다.
2. 유적명 필드와 필요 시 면적 필드를 지정합니다.
3. 출력 CRS를 확인합니다. 기본값은 `EPSG:5186`입니다.
4. Layout 모드를 선택합니다.
   - `기존 Layout 사용`: 기존 Layout 이름과 `Map Item ID`를 선택
   - `자동 Layout 생성`: 105 x 80 mm 임시 Layout 사용
5. **이전 시기 레이어 (Before 도면 고급 설정)** 섹션을 펼쳐 이전 시기 벡터 레이어들과 이름 매칭 필드를 선택합니다.
   - 개별 행별로 `[v] 외곽선 스타일 적용`을 체크하여 강제 빨간선(또는 원하는 색상/두께) 스타일링을 지정하거나, 체크 해제하여 원본 레이어의 스타일 렌더러를 복제해 유지할 수 있습니다.
6. 필요할 때만 표현 설정을 켜고, 기본 채움색/외곽선 또는 속성값별 색상 규칙을 지정합니다.
7. 검색창에 유적명을 2글자 이상 입력하고 `현재 유적 미리보기`를 실행합니다.
8. 오른쪽 패널에서 점유율 수치와 원형 도식을 확인합니다.
9. 출력 폴더와 출력 방식을 고릅니다.
10. `현재 유적 JPG 출력` 또는 `전체 유적 일괄 출력`을 실행합니다.

## 📊 점유율 안내

미리보기 패널에서는 아래 정보를 함께 보여줍니다.

- 가로 점유율
- 세로 점유율
- 도면 판정: `작음 / 적정 / 큼`
- 추천 축척
- 면적
- 원형 도식

원형 도식은 일본 국기처럼 **사각형 안에 원이 어느 정도 크기로 들어가는지**를 보여주는 간단한 시각화입니다.  
실제 형상을 정밀하게 그리는 기능은 아니지만, 도면 안에서 유적이 차지할 대략적인 비중을 직관적으로 판단하는 데 초점을 맞췄습니다.

## 🖼️ 출력 방식

- `최종도면 1장`
  - 배경 + 유적을 합친 최종 JPG 1장 출력
- `배경도 + 유적도 2장` (paired)
  - **이전 시기 레이어가 지정된 경우**:
    - **1번 도면 (Before)**: 매칭된 이전 시기 유적선이 강조된 도면 출력
    - **2번 도면 (After)**: 최종 유적 채움/외곽선이 강조된 도면 출력
  - **이전 시기 레이어가 지정되지 않은 경우**:
    - **1번 도면**: 배경 지형도만 있는 도면 출력
    - **2번 도면**: 배경 + 유적이 함께 있는 도면 출력

파일명은 유적명을 기준으로 안전하게 정리되며, 중복 시 `_001`, `_002` 같은 번호가 자동으로 붙습니다.

## 🧱 프로젝트 구조

- `archautomap.py`: 플러그인 진입점
- `dock_widget.py`: 도킹 패널 UI 및 사용자 이벤트 관리
- `core/engine.py`: 레이어 복제, 공간 매칭 Fallback, extent 계산, 렌더링, 출력 엔진
- `core/logic.py`: 축척/점유율/파일명 순수 수학 및 비즈니스 로직
- `core/constants.py`: 색상 팔레트, 크기, 스타일시트, 수학적 임계 상수 정의
- `core/settings.py`: 사용자 설정 저장 및 JSON 직렬화
- `CITATION.cff`: 인용 메타데이터
- `tests/test_logic.py`: 핵심 로직 유닛 테스트
- `dev_reload.py`: 개발 중 QGIS 메모리 강제 리로드용 모듈 캐시 초기화 스크립트

## 📌 참고 사항

- Before 레이어 및 외곽선 레이어 매칭 시, 유적명 오타가 있더라도 공간적 겹침(70% 임계값) 및 면적 제한 필터를 거쳐 자동으로 구제됩니다.
- 배치 출력 중 실패한 유적은 로그에 남기고 다음 유적으로 계속 진행합니다.
- PDF 출력, 부분 선택 배치 출력, 더 다양한 템플릿 기능은 후속 버전에서 확장할 수 있습니다.
